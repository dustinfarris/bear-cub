* User Story

As the person reviewing the kiosk before a deploy, I need one call that puts a kid's bonus cutoff a chosen number of minutes from now, so that every countdown state the gate asks for can be staged on the running dev server without touching the clock or the database by hand.

* Acceptance Criteria

** [ ] ~countdown(:morning, minutes)~ moves the shared Early Bird cutoff to that many minutes from now, and an already-open kiosk picks up the new schedule without a reload. (SC-1)
** [ ] ~countdown(:evening, minutes)~ sets every kid's Sleepy Bear cutoff to that many minutes from now, including a kid who had none today; ~countdown(:evening, [{kid_id, minutes}, ...])~ is the complete evening picture — each listed kid gets their own cutoff and an unlisted kid's existing cutoff is removed, so a kid with no evening bonus is staged in the same call. (SC-1)
** [ ] ~restore/0~ undoes a ~countdown/2~ call, bringing back the schedule from before the first staging scenario. (SC-1)
** [ ] The scenario is covered in ~test/bear_cub/dev/scenarios_test.exs~ and listed in the CLAUDE.md scenario list. (SC-1)
