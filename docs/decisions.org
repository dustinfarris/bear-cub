Repo-level decision log: one monotonic D-sequence across all initiatives, appended newest last — decision entries never live inside an initiative directory. Entry format (heading + CUSTOM_ID), citation links, chain-qualified pointers, the overrule protocol, and the append-only rule live in the workflow-kit org-conventions skill's Decision Log section. Entries are never edited or deleted; a reversal or overrule is a new entry citing the old.
